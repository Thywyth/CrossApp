# CrossApp
Наскрізний проєкт з крос-платформного програмування.

**Предметна область**: Склад  
**Сутності**: Product (товар), StockBatch (партія), Warehouse (склад), Movement (переміщення)  
**Призначення**: Облік залишків товарів по партіях та контроль переміщень між складами.

## Структура рішення (Solution)
* `src/Core` — спільна бібліотека класів (Class Library), ядро застосунку, незалежне від UI та зовнішніх фреймворків:
  * `Core/Dto/` — майбутнє місце для DTO (тиждень 3)
  * `Core/Domain/` — сутності доменної моделі (тиждень 4)
  * `Core/Storage/` — інтерфейси та реалізації сховищ (тиждень 5)
* `src/Cli` — консольний застосунок (клієнт), що використовує `Core` через ProjectReference.

## Збірка та запуск
```bash
# Збірка всієї системи
dotnet build

# Запуск консольного застосунку
dotnet run --project src/Cli

# Запуск із прапорцем JSON
dotnet run --project src/Cli -- --json
```

## Публікація застосунку
* **Self-contained** — містить копію .NET Runtime у каталозі публікації, тому застосунок працює на цільовій машині автономно без попередньо встановленого .NET SDK/Runtime.
* **Framework-dependent** — містить виключно скомпільований код застосунку та його бібліотеки, тому вимагає наявності встановленого середовища .NET відповідної версії на комп'ютері користувача.
